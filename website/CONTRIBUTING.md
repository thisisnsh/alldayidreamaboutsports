# Contributing

Short version: **this project isn't accepting pull requests.**

The macOS app and its backend are closed source and live in a private
repository. This repo holds the public landing page and privacy policy, and it's
published so people can see the site's source and read about how the app is
built — not as an invitation to collaborate. Pull requests, including small ones
and drive-by typo fixes, will be closed unread.

## What *is* welcome

- **Bug reports** — something broken on the site, or in the app itself.
- **Ideas and feature requests** — leagues, features, a Windows build.
- **Questions about the architecture** — the write-up lives in
  [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
- **Security reports** — please email rather than open a public issue.

Open an issue, or email
[support@alldayidreamaboutsports.com](mailto:support@alldayidreamaboutsports.com).

## Reusing the code

The site's HTML, CSS and JavaScript are published for reference, not released
under an open source licence — all rights reserved. If you want to use something
from it, ask.
